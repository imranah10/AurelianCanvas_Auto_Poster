# Privacy Policy — Aurelian Canvas

Last updated: 2026-10-08

Aurelian Canvas ("we", "our", "us") operates the website https://aureliancanvas.gumroad.com and the Pinterest API application "Aurelian Canvas Poster".

## What data we access

The "Aurelian Canvas Poster" application is used for a single personal Pinterest account (AurelianCanvas) only. Through the official Pinterest API it:

1. Reads the account's own board list (board names and IDs).
2. Creates Pins on the account's own boards, using images, titles, descriptions and links to Aurelian Canvas products.

## What data we store

- OAuth tokens (App ID, App secret, refresh token) are stored privately as encrypted GitHub Actions secrets. They are never shown publicly and never shared with any third party.
- Posted content metadata (pin IDs, schedule state) is stored in the private automation repository.

## What we do NOT do

- We do not collect, read or store any personal data of other Pinterest users.
- We do not access, follow, message or scrape any other account.
- We do not sell or share any data with anyone.
- We do not use the data for advertising or analytics.

## Data deletion

Access can be revoked at any time from Pinterest: Settings > Security and logins > Apps, then remove "Aurelian Canvas Poster". All stored tokens can be deleted on request.
